    So wird der Index berechnet

    Jeder Indikator wird standardisiert und so ausgerichtet, dass höhere Werte eine günstigere Lage bedeuten. Die Indikatoren werden zu vier Dimensionen gemittelt, die Dimensionen gleich gewichtet zum Gesamtindex zusammengefasst.

    100 entspricht dem Durchschnitt der oberfränkischen Kreise bzw. Gemeinden im gewählten Jahr. 110 liegt eine Standardabweichung günstiger, 90 eine ungünstiger. Gemeinden werden nur mit Indikatoren bewertet, die auf Gemeindeebene vorliegen.
